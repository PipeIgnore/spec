# 7. Cross-Package Contract

All canonical packages MUST agree on the following abstract model:

```text
Matcher:
    pattern + path + context
        -> boolean

Filter:
    path + arguments + context
        -> boolean

Core:
    document + path + matcher + filters
        -> ignored / included

CLI predicate adapter:
    boolean true
        -> emit original path

    boolean false
        -> emit nothing
```

The CLI path-stream model MUST NOT be confused with the in-process predicate
API.

This distinction is intentional.

For example:

```text
has(path, [".git"], context)
```

returns:

```text
true
```

whereas:

```text
printf PATH | pipeignore-has .git
```

outputs:

```text
PATH
```

Both represent the same predicate at different abstraction levels.

## CLI Predicate Stream Contract

Canonical predicate command-line interfaces SHOULD use a common adapter model.

A predicate CLI receives path records from standard input, evaluates each record
independently, and emits the original record only when the underlying predicate
returns `true`.

Conceptually:

```text
stdin path record
    ↓
predicate(path, arguments, context)
    ↓
true  -> emit original path record
false -> emit nothing
```

The adapter MUST NOT trim, normalize, canonicalize, or otherwise modify the
contents of a path record.

In the default text mode, path records are separated by newline characters.

Implementations MUST remove only the record delimiter itself. Other leading or
trailing whitespace is part of the pathname and MUST be preserved.

Canonical predicate CLIs SHOULD support a NUL-delimited mode, conventionally
selected using `-0`.

In NUL-delimited mode, NUL (`0x00`) is the only record separator. This mode is
RECOMMENDED whenever arbitrary filesystem paths must be represented safely.

A final record delimiter MUST terminate the preceding record and MUST NOT by
itself create an additional empty record.

An explicitly empty record occurring between two delimiters is a real input
record and MUST be passed to the predicate. The adapter MUST NOT silently
discard it.

The number of output records is not required to equal the number of input
records.
